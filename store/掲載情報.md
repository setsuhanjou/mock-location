## 2. ストアの掲載情報

### 説明（詳細）

```
Chrome 上の Web ページが取得する位置情報（navigator.geolocation）を、地図で指定した場所に差し替える開発者向けツールです。
位置情報を使う Web アプリの動作確認・デバッグを、実際に現地へ行かずに行えます。

■ 主な機能
・地点指定：地図をクリック、またはマーカーをドラッグして現在地を設定
・路線再生：地図上で経由点を指定し、指定速度で移動（終点で停止 / 始点から繰り返し / 往復）
・ジョイスティック：倒した方向・強さに応じて連続移動。方向キー / WASD でも操作可能
・座標の直接入力、プリセット地点の選択
・移動中は進行方向（heading）と速度（speed）も通知

■ 仕組み
Chrome DevTools の「Sensors」と同じく、Chrome DevTools Protocol の Emulation.setGeolocationOverride を使用して位置情報を上書きします。
有効中はブラウザ上部に「デバッグを開始しました」と表示されます。「キャンセル」を押すと差し替えが無効になります。

■ プライバシー
個人データは収集しません。設定は端末内（chrome.storage.local）にのみ保存されます。
外部への通信は、地図表示のための国土地理院タイルサーバー（cyberjapandata.gsi.go.jp）へのアクセスのみです。
```

- カテゴリ: デベロッパー ツール
- 言語: 日本語

## 3. プライバシーへの取り組み

### 単一用途の説明

```
Chrome 上の Web ページが取得する位置情報を、ユーザーが地図上で指定した座標・路線に差し替える開発者向けツールです。
```

### 権限が必要な理由

**storage**

```
ユーザーが指定した擬似位置（緯度・経度・精度・有効/無効）と、路線の経由点を端末内に保存するために使用します。
```

**debugger**

```
Chrome DevTools の「Sensors」と同じ Emulation.setGeolocationOverride コマンドで、タブの位置情報を上書きするために使用します。
差し替えを有効にしている間のみ、開いているすべてのタブにデバッガを接続し、このコマンドだけを送信します。
ページの内容の読み取り・変更や通信の傍受は行いません。
差し替えを無効にすると、すべてのタブからデバッガを切断します。
```

### リモートコード

- 「いいえ、リモートコードを使用していません」を選択
  - 地図ライブラリ（Leaflet）は拡張機能内に同梱しています

### データ使用

- 収集するデータ: **すべて未選択**（何も収集しない）
- 以下の 3 項目すべてにチェック:
  - 承認されている用途以外で、ユーザーデータを第三者に販売、転送しません
  - アイテムの単一用途と関係のない目的で、ユーザーデータを使用、転送しません
  - 信用力を判断する目的または融資目的で、ユーザーデータを使用、転送しません

### プライバシー ポリシー URL

- 空欄で可（ユーザーデータを扱わないため）

## 4. 配布
